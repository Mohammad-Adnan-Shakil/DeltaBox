DESIGN PHILOSOPHY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

DeltaBox should feel like opening a real F1 team's telemetry 
dashboard — not a student project, not a generic SaaS tool.

Every design decision must reinforce two emotions:
  Primary:   Confidence
  Secondary: Speed

Reference products for visual quality bar:
  Linear, Vercel, Apple, Stripe

Reference aesthetic:
  Mercedes AMG F1 telemetry dashboard
  Dark, precise, data-forward, purposeful

If a design decision does not reinforce confidence or speed,
reject it.

ANIMATION SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Animation Level: 3 — Interactive

Philosophy:
  Animation must serve a purpose.
  Never animate for decoration alone.
  Every animation must do at least one of:
    - Communicate state change
    - Guide user attention  
    - Improve perceived performance
    - Provide feedback
    - Reinforce speed/confidence emotion

Durations
  --duration-instant:  100ms   (immediate feedback)
  --duration-fast:     150ms   (hover states)
  --duration-normal:   250ms   (state changes)
  --duration-slow:     350ms   (page elements entering)
  --duration-slower:   500ms   (complex transitions)
  --duration-cinematic: 800ms  (hero, dramatic reveals)

Easing
  --ease-default:  cubic-bezier(0.4, 0, 0.2, 1)
  --ease-in:       cubic-bezier(0.4, 0, 1, 1)
  --ease-out:      cubic-bezier(0, 0, 0.2, 1)
  --ease-spring:   cubic-bezier(0.34, 1.56, 0.64, 1)
  --ease-sharp:    cubic-bezier(0.4, 0, 0.6, 1)

Approved animations
  Page transitions:     fade + slight Y translate (20px → 0)
  Cards entering:       fade + Y translate, staggered 50ms
  Hover on cards:       translateY(-2px), shadow increase
  Hover on buttons:     brightness increase + glow
  Prediction result:    scale in from 0.95, fade, duration-slow
  Confidence ring:      stroke-dashoffset animation, duration-cinematic
  Data numbers:         count up animation on enter
  Skeleton loading:     shimmer left to right
  Route change:         fade out 150ms, fade in 250ms

Forbidden animations
  Constant floating/bobbing elements
  Particle systems as background
  Rotation on data elements
  Animations longer than 800ms on UI chrome
  Animations that block interaction
  More than 3 simultaneous animations on screen

Reduced motion:
  Always respect prefers-reduced-motion
  Fallback: instant state change, no transition

BACKGROUND TREATMENTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Page base:
  background: --color-base-950
  
Subtle grid (optional, very low opacity):
  SVG grid pattern at 3-5% opacity
  Color: white
  Cell size: 32px

Aurora accent (hero/dashboard only, not every page):
  Two radial gradients, very subtle
  --color-accent-glow at 20-30% opacity maximum
  --color-data-primary (blue) at 10% opacity
  Position: top-right and bottom-left corners
  Never center the aurora — keep it peripheral

Noise texture (optional):
  Very subtle noise overlay at 2-3% opacity
  Adds depth without visual noise

Rule: Backgrounds should recede, not compete with content.
If the background is distracting, reduce opacity by 50%.

WHAT THIS SYSTEM FORBIDS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Never use:
  White or light backgrounds anywhere
  Generic blue as primary accent (blue is data-only)
  Rounded corners above radius-2xl on cards
  More than 3 font weights on one screen
  Animations longer than 800ms on UI chrome
  Particle systems as primary background effect
  Neumorphism (too subtle for dark backgrounds)
  Gradients on body text
  More than 2 accent colors visible simultaneously
  Comic Sans (obviously)
  Box shadows on text
  Borders thicker than 1px on cards

QUALITY BAR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Before shipping any screen ask:

Would this feel at home on Linear.app?
Would a senior designer at Stripe approve this?
Does this feel like F1 — fast, precise, premium?
Does every element have a reason to exist?
Is the data the hero, not the decoration?

If the answer to any question is NO — improve it.
